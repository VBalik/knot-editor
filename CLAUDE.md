# Редактор топологических узлов (knot-editor)

Отвечай пользователю только на русском: отчёты, статусы, вопросы. Интерфейс программы и сообщения коммитов остаются на английском.

## Что это
Одностраничное веб-приложение `index.html` (three.js r128 с CDN, без сборки): 2D-редактор диаграммы узла (рисование мышью, Random, загрузка картинки или фото кнопкой Image) и 3D-релаксация упругой трубки (L-BFGS, воркеры, WebAssembly-ядро пар). Полная история решений, физика, интерфейс и все версии — в `PROMPT-v2.md` (читай нужный раздел, а не весь файл: он большой).

## Правила работы
- **Ветка работы — `v3`.** С 2026-09-18 `main` перемотана на `v3` по решению пользователя: свежий клон и новая облачная
  сессия попадают на рабочее дерево, а не на июльскую оболочку. Дальше `main` обновляется только по просьбе (`git push origin v3:main`,
  только перемотка вперёд); помни, что из `main` собирается GitHub Pages, то есть это вторая публикация рядом с Netlify.
- **Сайт spring-knot.netlify.app публикует ветку `site`, и только её.** Обновлять `site` только по прямой просьбе пользователя («опубликуй на сайт» или похожей). Подробности — в разделе «Публикация и проверка» ниже.
- **Номер версии** растёт на 1 с каждой сборкой программы: `APP_VER_MINOR` в `index.html` и `<span id="appVer">` (сейчас 4.4, дальше 4.5, 4.6…). Изменения только в стенде или документах версию не меняют.
- **Каждая версия** описывается разделом «Версия X.Y» в `PROMPT-v2.md` перед разделом «Проект и публикация»; строка «сейчас X.Y» там же обновляется.
- **Коммиты выборочные:** называй файлы явно, никогда `git add -A` / `git add .`. Не коммитить сломанные состояния: сначала стенд.
- **Картинки пользователя** (фото и рисунки узлов) в репозиторий не добавлять: он публичный.
- Не менять физику молча: `bench.js` должен давать `hashMatch: true`. Хэши зависят от версии Node, поэтому эталоны разные для Air и облака. Если изменение физики задумано, сказать об этом пользователю и обновить эталоны в `test/bench.js` для каждой версии Node, где их можно пересчитать; для недоступной версии эталон удалить и написать об этом.

## Стенд (Node, без браузера)
Первый раз: `cd test && npm ci` (пакеты `three`, `jpeg-js`, `pngjs`; в облаке это делает хук SessionStart из `.claude/settings.json`).
Запуск: `cd test && node harness.js <тест.js>` — тест печатает JSON, у большинства есть поле `ok`.

| Тест | Что проверяет |
|---|---|
| `wsyntax.js` | синтаксис страницы и исходника воркера (`"syntax":"OK"`, `"fullSyntax":"OK"`) |
| `bench.js` | хэши траекторий сверяются с эталоном для текущей главной версии Node, итог в поле `hashMatch` (`true` — совпало, `null` — эталона для этой версии нет). Эталоны в начале `test/bench.js`: Node 26 (Air) и Node 22 (облако) |
| `battery.js` | пресеты узлов сходятся, тип (det) сохраняется |
| `uiwins.js`, `uisel.js`, `besttie.js` | окна попыток, выбор кликом, «липкий» рекорд |
| `stir8.js` | Stir (раздутие ×k) сохраняет тип узла |
| `pending.js` | белые кружки у невыбранных проходов, блокировка Physics |
| `imgknot.js` | распознавание синтетических картинок, 10 стилей (`IK_STYLES=clean,graph IK_N=5,12,26 IK_SEEDS=1` — быстрый прогон); ожидание при `IK_SEEDS=3`: 22/22 во всех десяти стилях |
| `imgphoto.js` | картинка с диска: `IK_IMG=<файл .jpg/.png> IK_EXPECT=<пересечений>,<det>` |
| `sketchgen.js` | 50 шумных скетчей на разной бумаге → `out/sketches/` + манифест с эталоном (`SK_DIR`, `SK_N`, `SK_SEED0`, `SK_OFF` — другая партия) |
| `sketchrun.js` | те же картинки с диска через путь кнопки Upload; ожидание: 49/50 точных на первой партии, 47/50 на проверочной (`SK_DIR`, `SK_ONLY`, `SK_VERBOSE`) |
| `draw2d.js` | **вид 2D в PNG**: настоящая растеризация холста (`KNOT_CANVAS=canvas2d.js node harness.js draw2d.js`; `KNOT=trefoil\|figure8\|cinquefoil\|septafoil\|rN\|open\|img`, `IK_IMG=<файл>` для `img` — рисунок от руки со всеми дрожаниями, `FLIP=<номера>` — переключить проходы, `DRAG=<доля,dx,dy>` — потянуть верёвочку, `SEED`, `SCALE=1..4`, `OUT`, `BG`, `DOTS=0`) |
| `dropzone.js` | перетаскивание картинки в поле 2D: подсветка зоны, выбор картинки среди файлов, передача в `ikLoadFile` |
| `drag2d.js` | режим редактирования: курсоры (ладошка/указатель), узел тянется за рукой, верёвка не удлиняется, тип узла и выбранные проходы сохраняются, клик по кольцу по-прежнему переключает проход |

Флаги: `NOWASM=1` — JS-путь ядра пар, `KNOT_PAGE=<файл>` — другая страница.
Отладка распознавания: `skdraw.js` (маска, скелет, кривая, мосты, эталон в PNG), `skbad.js` (перепутанные проходы), `skbr.js` (мосты), `skcrop.js` (кусок исходника).

## Публикация и проверка
- **Работа** идёт в `v3`: push в `v3` на сайт не попадает и кредиты Netlify не тратит.
- **Проверка у пользователя:** он скачивает `v3` на свой Mac командой `git -C "/Users/balik/Library/CloudStorage/GoogleDrive-gbalik@gmail.com/My Drive/Programming/Claude/Knots" pull` и открывает `index.html`. В конце работы напомни ему эту команду и назови номер версии, который он должен увидеть.
- **Публикация по просьбе пользователя:** убедись, что изменения закоммичены и отправлены в `v3`, что `wsyntax.js` и `bench.js` (`hashMatch`) проходят; затем `git fetch origin` и `git push origin v3:site`. Это должна быть перемотка вперёд: если git отказывает (ветка `site` разошлась с `v3`), ничего не форсируй и спроси пользователя. Каждая публикация тратит 15 кредитов Netlify, поэтому одна публикация на одну просьбу.
- **После публикации** проверь, что сайт отдаёт новую версию: `curl -s https://spring-knot.netlify.app/ | grep -o 'id="appVer">[^<]*'` (сборка занимает около минуты; в облаке сайт может быть недоступен по сети — тогда так и скажи).

## Облако
В облачной сессии нет живого браузера. **Вид 2D-холста проверяется стендом:** `test/canvas2d.js` — настоящая растеризация Canvas 2D, `draw2d.js` рисует диаграмму в PNG (см. таблицу выше), картинку можно открыть и посмотреть. Всё остальное (вёрстка страницы, кнопки, рамки, 3D, поведение мыши и перетаскивания в живом браузере) стендом не проверяется — честно скажи пользователю, что именно не проверено, и попроси посмотреть в браузере.
`python3 serve.py 8742` — локальный дев-сервер (статика и приём телеметрии в `telemetry/`, эта папка не коммитится).
